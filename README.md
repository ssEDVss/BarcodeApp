# BarcodeApp — агрегатор отзывов и цен на товары по штрихкоду

> **Статус проекта:** 🚧 В активной разработке (MVP).  
> Приложение разрабатывается в рамках курсового проекта по специальности **09.02.07 «Информационные системы и программирование»** (КГБПОУ «Норильский техникум промышленных технологий и сервиса»).

## О проекте

Мобильное Android-приложение для быстрого поиска и сравнения цен, а также просмотра и публикации пользовательских отзывов на товары по их штрихкоду.

## Реализованный функционал (текущий этап)

- Базовый пользовательский интерфейс на **Jetpack Compose** (`ScannerScreen`).
- Локальное хранение и получение данных по коду товара.
- Форма добавления отзыва о товаре:
  - оценка (рейтинг);
  - указание магазина;
  - ввод цены в рублях (`₽`);
  - текстовый комментарий.
- Отображение списка сохранённых отзывов и цен по выбранному товару.
